## 3. 디자인 시스템 (TDS) 스타일 토큰

- **배경 캔버스**: `#F2F4F6` (TDS Fill-Secondary) 및 본문 화이트 컨테이너
- **카드 스타일**: 
  - 기본 배경: `#FFFFFF` 또는 `#F8FAFC`
  - 테두리: `border border-slate-200/80` (1px Subtle Divider)
  - 모서리 곡률: `rounded-2xl` (16px)
  - 그림자: `shadow-xs` ➔ 호버 시 `shadow-md`
- **타이포그래피**:
  - 이름: 20px / Line-height 28px (Bold, `#191F28`)
  - 카드 제목: 15px / Line-height 22px (Semibold, `#191F28`)
  - 카드 설명: 13px / Line-height 18px (Regular, `#6B7684`)
- **터치 타깃 크기**: 모바일 접근성을 위해 각 링크 카드의 최소 높이 **64px 이상** 유지
